# Сайт №04: комикс-сериал «Один в поездке»

Копия вёрстки Behance «Landing-сериал». Тема-заглушка: три ситуации в поездке и фразы на английском и турецком. В конце реклама Dias English и Alterna Timur.

- `gh/` публикуется на GitHub Pages. `gh/index.html` с рекламой, `gh/lesson/index.html` без неё.
- `design/` образец: скриншоты владельца и `design/ref/` модули с Behance.
- `qa/` проверки Playwright и скриншоты.
- `tools/media.py` собирает картинки в `gh/media/`.

## Как поменять текст и ссылки
Всё в `gh/content.js`.
- `links.dias`, `links.timur` ссылки покупки. Все кнопки берут их отсюда.
- `links.social` ник и ссылка на инстаграм (сейчас заглушка). По этой ссылке строятся оба QR-кода.
- `blocks` список блоков по порядку. Убрать блок: удалить его из списка. Повторить: скопировать. Переставить: перенести.
- `ad: true` значит блок есть только на главной, на `/lesson/` его нет.
- Облачко: `lang: 'en'` белое, `lang: 'tr'` бежевое; `x`, `y` позиция в процентах кадра; `ru` перевод мелким шрифтом.
- В текстах можно `<b>` (выделение цветом) и `<br>`.

## Цвета и шрифты
`gh/assets/style.css`, блок `:root` в начале файла. Шрифты лежат в `gh/assets/fonts/`, подключены в `gh/assets/fonts.css`.

## Картинки
1. Положи webp в `gh/media/` (до 1600 px, до ~250 КБ) или поправь источники в `tools/media.py` и запусти `python3 tools/media.py`.
2. Скрипт заново пишет `gh/assets/sizes.js` (ширина и высота для разметки). Если кладёшь файл руками, допиши его размер туда же.
3. В `content.js` пиши имя файла без `media/` и без `.webp`.

## Проверка
```bash
python3 -m http.server 8704 --directory gh
```
```bash
node qa/shoot.mjs http://localhost:8704/ 1440,834,390
```
Скрипт проверяет боковую прокрутку, загрузку картинок, ошибки консоли и ссылки lava.top, кладёт скриншоты в `qa/shots/`.
